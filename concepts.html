Study Guide

Key Concepts

This page summarizes important terms connected to Chrome and modern web browsing. It also prepares readers for the quiz page.

1. Domain Name System (DNS)

DNS helps browsers locate the correct server when a user types a website address. It translates domain names into IP addresses used for internet communication.

2. HTTP and HTTPS

HTTP is the protocol used to transfer web resources between a browser and a server. HTTPS is the secure version that encrypts data during transmission.

3. Rendering Engine

A rendering engine reads HTML and CSS and converts them into the visible structure and style of a webpage. Chrome uses Blink as its rendering engine.

4. JavaScript Engine

A JavaScript engine runs the scripts that make webpages interactive. Chrome uses the V8 engine to execute JavaScript efficiently.

5. Sandboxing

Sandboxing is a security approach that limits what a browser process or webpage can access. This reduces damage from malicious content.

6. Progressive Web Apps (PWAs)

PWAs are websites that act more like installed software. They can support offline use, notifications, and app-like experiences.

Concept Review List

  • DNS connects the browser to the correct server.
  • HTTP and HTTPS transfer data over the web.
  • Rendering engines display page layout and style.
  • JavaScript engines support dynamic behavior.
  • Sandboxing improves security.
  • PWAs show how browsers continue to evolve.
